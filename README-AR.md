# مكتبتي الطبية — الإصدار 1.1

تطبيق ويب تقدمي (PWA) للآيفون والآيباد والكمبيوتر. يبدأ بتسع مواد دراسية، وكل مادة تحتوي **صفر محاضرات**. لا توجد محاضرات قديمة أو تجريبية.

## تشغيله ونشره

1. ارفع ملف `medical-library-app-ready.zip` كاملًا إلى **Cloudflare Pages → Workers & Pages → Create application → Pages → Drag and drop your files / Direct Upload**. تستطيع رفع الملف المضغوط للموقع كاملًا في هذه الخطوة فقط؛ هذا الملف يخص نشر التطبيق، لا النسخة التي يرسلها الطالب لزميله.
2. افتح عنوان `https://YOUR-PROJECT.pages.dev/` الذي يعطيك إياه Cloudflare عبر Safari.
3. من Safari اختر **مشاركة → إضافة إلى الشاشة الرئيسية → فتح كتطبيق ويب → إضافة**.
4. افتح التطبيق مرة واحدة مع الإنترنت، ثم اختبره بوضع الطيران.
5. داخل التطبيق: اختر المادة ثم **إضافة محاضرة** وحدد ملف HTML أو PDF من تطبيق الملفات. اكتب الاسم والترتيب ثم احفظ.
6. لتبادل المكتبة بين الطلاب: **النسخ والمشاركة → إنشاء نسخة للمشاركة → مشاركة النسخة**. يظهر ملف `.medlib` واحد، وليس ملف ZIP يحتاج الزميل إلى فكّه. على الجهاز الآخر: **النسخ والمشاركة → اختيار نسخة للاستيراد**، ثم «إضافة وتحديث» أو «استبدال مكتبتي بالكامل».

## أين تُخزن المحاضرات؟

- تُخزن الملفات محليًا في **IndexedDB** على كل جهاز. الموقع لا يرفع الملفات ولا يحتاج خادمًا أو حسابًا لاستضافتها.
- يحتفظ **Service Worker** بملفات واجهة التطبيق على الجهاز. يجب فتح الموقع أول مرة على اتصال HTTPS ثم انتظار اكتمال تسجيله قبل اختبار وضع الطيران.
- يفتح كل ملف في نفس القارئ المتجاوب تلقائيًا على الهاتف واللوحي وفي أي اتجاه للشاشة، دون أي اختيار أو وضع منفصل. تعتمد ملاءمة محتوى HTML **داخليًا** أيضًا على تصميم ملف المحاضرة نفسه؛ يوفر التطبيق أدوات تكبير وتصغير.
- تظهر HTML داخل iframe sandbox `allow-scripts allow-forms allow-modals allow-downloads` **بدون** `allow-same-origin` للحد من وصول سكربتات المحاضرات إلى بيانات المكتبة. محاضرات HTML التي تعتمد على `localStorage` خاص بها أو ملفات خارجية قد تعمل جزئيًا أو تحتاج تعديلًا في مصدرها. من الأفضل استخدام محاضرات HTML تحتوي أصولها وصورها المضمنة وتعمل دون إنترنت.
- ينقل ملف `.medlib` محتويات ملفات المحاضرات نفسها مع عناوينها وترتيبها، دون ترميز Base64 لكل ملف. يحتوي رأس بيانات JSON ثم البايتات الأصلية؛ صُمم لتقليل استهلاك الذاكرة أثناء إنشاء النسخة والاستيراد.
- الاستيراد يعمل في معاملة IndexedDB واحدة: إما ينجح كاملاً أو لا يستبدل البيانات القديمة في حال الخطأ.
- هذا ليس تطبيق App Store أو ملف IPA؛ تثبيته يتم من Safari بإضافة الموقع إلى الشاشة الرئيسية.

## تنبيهات مهمة

- بيانات IndexedDB ليست ضمانًا دائمًا إذا مسح المستخدم بيانات الموقع أو أزال التطبيق أو حُذفت بيانات التخزين بواسطة النظام. احتفظ دومًا بنسخة `.medlib` في تطبيق الملفات أو iCloud.
- قد لا تعمل بعض الوسائط المضمنة في ملف HTML إذا كانت تعتمد على الوصول إلى نطاق الإنترنت أو أذونات المتصفح أو السماح بالوصول إلى أصل الموقع.
- تشغيل التطبيق بالتصفح الخاص أو عبر `file://` ليس مسار نشر صالحًا؛ يتطلب HTTPS أو localhost للتخزين دون اتصال بشكل موثوق.
- الاحتفاظ بالنسخة الاحتياطية على الجهاز نفسه وحده ليس بديلًا عن نسخة خارجية.

## محتويات الموقع

- `index.html`: واجهة التطبيق.
- `app.js`: قاعدة البيانات المحلية، عرض المحاضرات، الترتيب، التحرير، الاستيراد، وتصدير `.medlib`.
- `styles.css`: تصميم واحد متجاوب تلقائيًا مع مختلف الشاشات والاتجاهات.
- `sw.js`: التخزين المؤقت لملفات التطبيق.
- `manifest.webmanifest`: بيانات تثبيت التطبيق.
- `icons/`: أيقونات التطبيق.
- `_headers`: ترويسات أمان بسيطة للاستضافة على Cloudflare Pages.

يمكن رفع هذه الملفات أيضًا إلى GitHub Pages، مع بقاء `index.html` في جذر مجلد النشر.
